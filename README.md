# 🚓 경찰청 인트라넷 시스템

이 프로젝트는 경찰청 내부 운영을 위한 **데스크탑 기반 인트라넷 시스템**입니다.  
출퇴근 관리, RP 기록, 사건 보고, 면허 신청 등 주요 기능을 포함하고 있으며,  
Windows 환경에서 `.exe` 파일로 실행됩니다.

---

## 📦 기능 요약

- 출퇴근 버튼 기록 시스템
- RP 기록기 (성공/실패 점수 관리)
- 사건처리 보고서 시스템
- 법률 계산기 (벌금/구금/보석금 계산)
- 면허 발급 신청 기능 (헬기/항공)
- 관리자 전용 사용자 차단 기능
- 감사팀 엑셀 로그 출력
- 실시간 공지/사이드공지 등록
- 사용자 승인 및 이메일 인증
- 역할 기반 페이지 접근 제어 (관리자, 감사팀, 경찰청)
